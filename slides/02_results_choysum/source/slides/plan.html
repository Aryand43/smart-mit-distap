The sequence for the paper: for each crop (choy sum, then kailan, then Arabidopsis), run each data type (three-band images, Raman spectra, and the fusion of both) through all five models, and test every combination the same way: leave one plant out, white-light normalisation from training plants only, settings tuned on training plants only. That gives one comparison table per crop and data type.
