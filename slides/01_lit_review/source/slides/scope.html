Scope

What this review looks for

Problems

  • Disease classification
  • Stress classification, any type: drought, nutrient, light, biotic
  • Early detection and time-point classification: how soon, and how long since stress began

Techniques

  • Image preprocessing and band selection
  • Hand-made features with classical ML
  • CNNs and transfer learning
  • Hybrid CNN-LSTM, CNN-transformer and encoder-decoder models

Conditions of interest

  • White-light and low-light imaging
  • Controlled stress experiments, such as 4-hour exposures
  • Data collected at several time points

Each paper is logged as: problem · ML/DL technique · reference · authors · year. Focus: RGB and three-band images; spectral work included for comparison.

Per Dr Praveen's 8 Oct message: stress can be anything, not only light stress. The main goal is the methods used for RGB image classification and preprocessing. Spectral (hyperspectral/Raman) papers appear only as a comparison point.
