Coding plan

1

Review the sample set. Check the three-band images, labels and time points.

2

Prepare data. Organise by condition and time point; normalise; segment plants from background.

3

Baselines. Hand-crafted features with SVM or gradient boosting; a fine-tuned CNN (ResNet-50, DenseNet-121) on single images.

4

Hybrid models. CNN-LSTM on each plant's image sequence, plus a CNN-vision transformer; each crop first, then crops combined.

5

Explore and evaluate. Try an encoder-decoder variant; report accuracy per time point and condition, with saliency maps.

Baselines come first so the CNN-LSTM has something to beat. The architecture will be refined once the sample set has been reviewed.
